# PNDS creation / PNDS 创作

Keep one task context: author goal, existing project identity, source evidence, confirmed decisions and pending work. Read existing decisions, validation and creator-handoff first. Use the installed App corpus via [platform sources](reference/platform-sources.md); resources and tools are self-contained in this directory.

Compose only the capabilities the task needs. If the harness can invoke the corresponding installed Skill, it may do so; installing other Skills is unnecessary because the same capability resources are bundled here. Without native Skill invocation, read the linked capability and record that limitation.

| Task | Capability composition |
| --- | --- |
| New project | Establish the author's goal with [discussion](capabilities/assess.md), then [runtime preparation](capabilities/adapt-runtime.md), selected [modules](capabilities/integrate-modules.md) and [validation/handoff](capabilities/validate-handoff.md). Investigate provided materials when needed. |
| Modify existing PNDS | [Investigate](capabilities/investigate.md) current identity/behavior/records, confirm any necessary artistic changes with [discussion](capabilities/assess.md), then apply only the requested adaptation/module work and [validate/handoff](capabilities/validate-handoff.md). Never initialize it again. |
| Arbitrary-source conversion | [Investigate](capabilities/investigate.md), then [assess](capabilities/assess.md). Deliver the report and concrete proposal before rewriting; proceed with runtime/module implementation only after author confirmation of that plan. Pure assessment can end with the report. |

Do not require a p5/SuperCollider/TouchOSC triple, choose an audio mode/topology/role/seat policy by default, or use a fixed artistic fidelity ranking. Preserve sound, visual meaning, interaction and timing; necessary changes belong to the author and enter [source records](reference/records.md).

Default delivery is editable source plus decisions, actual validation and next tasks. A complete initial structure may return to App creation mode while runtime/sound are pending; actual creation-mode opening is verified only by observed App operation. Package only for an explicit distribution goal. `pnds-cm1` is a separate, explicitly chosen course entry with its own triple and source-plus-bundle requirements; never auto-select that course workflow.

Missing resources, tools or version evidence constrain the affected step. Preserve useful progress and state those limits. No automatic installation/execution of Skills in other agent environments, new App assessment entry or automatic module installer is provided.
