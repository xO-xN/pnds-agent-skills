# PNDS conversion / 任意来源评估与移植

Use the same creation composition as the unified entry; this directory includes all its needed resources and needs no installed sibling Skill.

1. [Investigate](capabilities/investigate.md) actual materials, current identity and prior records. Non-triple and incomplete sources are valid assessment inputs.
2. [Discuss feasibility](capabilities/assess.md), using [installed App sources](reference/platform-sources.md). Deliver facts, limitations, routes, gaps and a concrete proposal first. Pure assessment can finish here; conditional or presently infeasible outcomes are valid.
3. Only after the author's explicit confirmation, [adapt runtime](capabilities/adapt-runtime.md) and [integrate selected modules](capabilities/integrate-modules.md) as needed. Read confirmed decisions instead of asking for them again. Necessary sound, visual, interaction or timing changes require author agreement and reasons in the source record.
4. [Validate and hand off](capabilities/validate-handoff.md) editable initial source with separate structure/wiring/runtime/sound/performance evidence. No distribution intent means no automatic .pnds. Missing sound/device verification does not erase a complete initial structure.

No fixed Internal/External/None, local/telematic, hub, role, seat or fidelity ranking applies to general conversion. Do not reinitialize an existing PNDS identity/token namespace or import a reference work's artistic policies.

For actual TouchOSC materials, the bundled parser is described in [tools](reference/tools.md). The old Co-here telematic material remains under [legacy guidance](reference/legacy-scope.md); read it only for an explicitly selected matching legacy architecture after author discussion. It is case-specific prior art, not a prerequisite or general policy. CM1 stays an explicitly chosen independent course entry and is never inferred merely from supplied triple files.

Use native Skill invocation if available; otherwise read the bundled capabilities directly and record the limitation. Skills installation is optional; this workflow does not change other agent environments or add an App conversion entry.
