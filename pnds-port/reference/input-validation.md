# Legacy triple inventory

This is conditional format guidance for an explicitly selected p5/SuperCollider/TouchOSC case. A triple is not required by general investigation or assessment.

Inspect actual p5 source (all files, linked resources and library versions), SynthDefs/OSCdefs/routines/buffers/plugins in supplied `.scd`, and each supplied `.tosc` with `node tools/tosc-parser.mjs <file>`. Correlate OSC addresses, types, ranges and defaults. Multiple layouts need actual source evidence or the author's account of their assignment.

A link alone proves neither access nor source completeness. Retrieve it through available authorized tools; if inaccessible, request only decision-relevant missing material and preserve the partial report. An unparseable file limits that source's analysis rather than invalidating every other material. Third-party UGens or missing samples are compatibility questions for the installed App; flag them before proposing implementation.

Instructions are author evidence; contradictions with code become explicit questions. Do not automatically discard MIDI, feedback, unmatched senders or listeners; investigate their use before proposing any change.
