# Portable helpers / 辅助工具

Every published Skill directory includes its needed tools and references. No installed sibling Skill is required. Tools use Node 24 and built-in modules; packaging also needs `zip`, archive inspection needs `unzip`; compilation requires an independently available `sclang`. Missing tools are reported as limitations, not silently installed.

- `node tools/tosc-parser.mjs <layout.tosc> …` parses raw XML, zlib and gzip TouchOSC layouts into a nested JSON control inventory. Only use it for TouchOSC materials; it is not a prerequisite for arbitrary-source assessment. It is a format-specific inventory tool, not a full XML validator or an OSC semantic verifier.
- `node tools/platform-info.mjs --app <PNDS.app> [--locale en|zh-CN]` inventories installed reference files and version. Missing corpus/version is an explicit failure with diagnostic paths; no network fallback occurs in the tool.
- `node tools/pack.mjs <project> [--out <directory>] [--overwrite]` performs static, offline packaging with temporary staging, source containment, dependency/SynthDef checks, contract exclusions, Unix permissions, single-root ZIP, atomic output and SHA256. It never runs npm, compiles, or starts the project. Output must be outside the source; overwrite requires an explicit decision. Without --overwrite, publication atomically refuses a concurrently created destination; this requires a destination filesystem with hard-link support (choose a local supported directory if unavailable).
- `node tools/smoke.mjs <project> [--timeout-ms <milliseconds>]` is a separate, explicit None-mode execution check on an isolated source copy with free ports. It starts only the copied project's declared server, checks the full minimum health shape/identity/ports, then stops and waits for that child. It cannot verify audio, native embedding or device input. Use only when project execution is authorized and None is supported. No npm or scsynth is started.

The pack helper validates the documented protocol-1 static subset, not future App rules or execution behavior. Prefer the installed App's creation workbench “Generate .pnds” for its complete version-specific validation. Always review the matched installed manual, validate the archive and complete an installation round trip when distributing. The App packer and the external helper do not silently repair missing dependencies or compiled assets.
