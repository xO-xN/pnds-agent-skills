# Explicit distribution

General conversion defaults to editable source and records. Package only after explicit distribution intent. Use the matched installed App's creation workbench “Generate .pnds”, or the portable static helper in [tools](tools.md), then inspect layout, SHA256 and installation round trip. Do not force a hub, role or universal endpoint package strategy.

Current bundle rules preserve arbitrary runtime files and permissions; exclude `.git*` and `.DS_Store` at any depth and root docs/test/tests directories. Materialize in-project symlinks, skip outside targets; declared paths/dependencies/SynthDefs must remain valid. The helper never runs npm or a smoke server. Explicit None smoke is a separate tool/check. Bump version for changed distributed contents; retain id.
