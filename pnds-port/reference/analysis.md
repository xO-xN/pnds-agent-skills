# Legacy triple analysis

Use only for a matching, explicitly selected triple scenario, alongside the bundled investigation capability. [Co-here](case-co-here.md) illustrates one report's evidence depth.

Inventory p5 score sections, clock/transport, visual meaning, input handlers, network calls and persistence. Inventory SC SynthDefs, parameters/mapping math, envelopes/routines, resource allocation, voices, bus outputs and external dependencies. Inventory TouchOSC paths, argument types/ranges/defaults, layout, simultaneous input and feedback/MIDI paths. Cross-reference actual senders/receivers; unresolved or apparently unused content remains unverified until evidence or author discussion resolves it.

Infer neither venue topology nor voice ownership from filenames alone. Record actual deployment evidence, current shared/local state, authority and timing tolerance. Propose any transport/state changes to the author. Which events or continuous values need relay, what remains local, and acceptable clock drift are work decisions; this reference imposes no universal sync set or fidelity ranking.
